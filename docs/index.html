🚌 CityPulse

Live transit mission control — a 3D globe of real buses, an AI copilot, and a PM brief generator. AI Engineer + Product Management portfolio project.

PROBLEM

Transit agencies publish GTFS-realtime feeds — live vehicle positions, occupancy, delays — but the data stays invisible inside developer APIs. Riders guess at crowding; planners work from static schedules. The live network deserves a live interface.

SOLUTION

CityPulse is a static 3D web app with a beating heart: a GitHub Action ETL that parses GTFS-realtime protobuf every 5 minutes into compact JSON. The frontend — Three.js globe, MapLibre city view, deterministic AI copilot — renders ~1,300 real vehicles with zero API keys and zero backend.

ARCHITECTURE

GTFS-RT (MBTA, RTD) ──5min──▶ Action ETL ──▶ data/live/*.json ──▶ static 3D site
   protobuf                 parse+join routes   same-origin JSON    globe / map / copilot
  • Why Action-ETL, not browser fetch: GTFS-RT endpoints lack CORS headers; protobuf parsing belongs server-side.
  • Why static-first: free GitHub Pages hosting, no backend to operate — "live" via 5-minute snapshots with honest timestamps.
  • Why deterministic copilot: answers are computed from the actual snapshot — reproducible, keyless, no hallucinated numbers. The LLM is an optional upgrade.

KEY DECISIONS

  • Feeds were verified by parsing, not by docs. Six candidates probed; only MBTA + RTD made the cut (open, keyless, occupancy populated). Seattle's feed was realtime-verified but cut for unresolvable route IDs — documented, not faked.
  • Honest unknowns. Feeds omit speed/delays/rail occupancy → the UI shows "—" and the copilot explains why, instead of inventing data.
  • Prebuilt route lookups. 24 MB GTFS zips baked into 63 KB JSON once; the hot ETL stays dependency-light and fast.

IMPACT

Demonstrates the full AI-engineer loop — real-time data ingestion, protobuf ETL, agentic tool use over live data — plus product-management craft: KPI design, honest data states, a one-click network brief. The demo is the portfolio piece: spin the globe and the data moves.
